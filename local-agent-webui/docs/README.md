# 本地 Agent WebUI 搭建教程

通过七个阶段，把聊天界面接到本地 Pi Agent：先启动服务，再接通模型、原生会话、工具审批、Skill 和提示词，最后检查完整流程。

[开始阅读图文教程](tutorial/本地-Agent-WebUI-搭建教程.md)

## 按搭建顺序阅读

| 阶段 | 操作内容 | 完成后能看到什么 |
| --- | --- | --- |
| [一：准备环境](tutorial/本地-Agent-WebUI-搭建教程.md#阶段一准备环境启动本地服务) | 配置 Pi、获取代码、安装依赖、设置演示目录 | Pi 能回答，网页能打开 |
| [二：搭建聊天界面](tutorial/本地-Agent-WebUI-搭建教程.md#阶段二复用官方组件搭出聊天界面) | 复用组件、布局、字体和主题 | 消息区、输入区与模型选择入口可用 |
| [三：读取模型配置](tutorial/本地-Agent-WebUI-搭建教程.md#阶段三读取本机配置让模型选择生效) | 读取本机模型和支持的思考档位 | 模型菜单与 Pi 配置一致 |
| [四：打通对话与恢复](tutorial/本地-Agent-WebUI-搭建教程.md#阶段四打通对话并让会话可以恢复) | 创建 Harness 会话、连接消息流、保存上下文 | 能聊天，刷新与重启后能续聊 |
| [五：工具调用与审批](tutorial/本地-Agent-WebUI-搭建教程.md#阶段五展示工具调用并接通批准与拒绝) | 展示工具参数、结果与审批状态 | 批准后执行，拒绝后停止受控调用 |
| [六：加载 Skill 和提示词](tutorial/本地-Agent-WebUI-搭建教程.md#阶段六加载-skill-和提示词显示实际来源) | 加载资源、显式调用 Skill、查看提示词来源 | Agent 依据任务说明读取文件并回答 |
| [七：完成验收](tutorial/本地-Agent-WebUI-搭建教程.md#阶段七完成验收运行完整工作台) | 运行检查、验证浏览器操作、生产启动 | 关键流程通过，失败可沿调用链定位 |

每个阶段包含操作目标、步骤、关键代码、可交给 AI 的提示词和完成标志。源码中的完整文件用于运行，教程内标明的代码节选用于讲解。

## 配套内容

- [案例运行说明](../README.md)：快速启动、配置项和当前能力。
- [组件来源与校验](references/components.md)：对应教程的界面搭建与来源检查。
- `tutorial/images/`：正文引用的六张运行截图，覆盖聊天、工具审批、执行结果、Skill 和提示词。

截图来自独立临时工作目录中的实际运行。聊天回复使用已配置模型，工具结果来自真实文件读取与本机命令执行；截图用于说明操作状态，不代表所有供应商或 MCP 服务均已验收。

## 文档目录

```text
docs/
├── README.md                       阅读入口与阶段导航
├── tutorial/
│   ├── 本地-Agent-WebUI-搭建教程.md  完整图文教程
│   └── images/                     正文运行截图
└── references/
    ├── components.md               组件来源与校验说明
    └── ui/
        ├── AI-ELEMENTS-SOURCES.json 原组件清单与快照路径
        ├── UI-SOURCES.json         主题及基础组件摘要
        ├── HARNESS-UI-SOURCES.json  资源面板组件摘要
        └── upstream/               校验所需的上游原始快照
```

`references/ui/` 中的 JSON 与快照由 `npm run verify:ui` 使用。调整目录时同步修改清单和脚本中的路径，并运行来源检查；组件正文和预期摘要应保持来源版本。
