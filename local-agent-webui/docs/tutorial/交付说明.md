# 教程与配套源码

[阅读完整教程](本地-Agent-WebUI-搭建教程.md)。正文按“背景介绍 → 依赖介绍 → 七个搭建阶段 → 总结”组织，每个阶段提供目标、操作步骤、代码或提示词，以及完成标志。

## 如何使用

1. 将正文、`images/` 目录和 [源码包](ai-web-chat-tutorial-source.zip) 一起交给读者；[图文教程整包](本地-Agent-WebUI-图文教程.zip) 已将这些文件放在一起。
2. 读者先阅读背景和依赖，再按阶段一解压、安装和配置自己的 Pi 认证。
3. 按阶段二至六依次完成界面、模型配置、对话恢复、工具审批与资源加载；完整文件在源码包中，正文明确标记节选。
4. 按阶段七验证真实供应商、工具、审批、Skill 和原生恢复。

源码包根目录名为 `ai-web-chat`。包中包含 151 个文件，含完整运行源码、锁文件、测试、官方组件来源快照、上游授权与逐文件摘要。未包含个人认证、个人配置、个人 Skill 原文、会话数据、依赖安装目录和构建缓存。包内 README 和环境变量示例按当前完整 Harness 版本整理，避免沿用工程早期说明。

## 验证范围

初次编写教程时，重新运行并通过了类型检查、10 项自动化测试和官方 UI 来源校验；解压后的源码包也独立通过来源校验。本次按审阅意见重组文章，核对了标题层级、七个阶段、源码节选、链接及包摘要，没有修改产品代码或源码包。

本次另启动独立演示实例，补充了 6 张真实运行截图，覆盖聊天、等待审批、批准后的本机命令输出、Skill 原文、显式 Skill 调用和实际提示词来源。截图使用临时工作目录及教学文件；聊天和 Skill 回答来自已配置模型的实际调用，不是模拟回复。

生产构建是此前交付已通过的结果，本次补图未重跑产品测试和构建，也不代表重新完成所有浏览器流程或真实 MCP 服务验收。既有自动化测试使用本地模拟模型服务与真实官方 Harness/工具执行；本次截图中的对话则使用实际供应商。

当前工程的 `local-sandbox` 是宿主执行适配，并不提供操作系统隔离。源码默认仅监听本机回环地址。模型计算位置取决于供应商端点。
